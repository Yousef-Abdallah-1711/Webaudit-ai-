**GATING (read before dispatching ANY task)**:

- **Every task in this file is gated by SG1** (007, 008, 009 runtimes landed, including 009 U-1 tasks T-U1-1..T-U1-10 proven by a behavioral self-test; plan.md SG1). **Nothing starts until the SPEC 012 closure-and-freeze pass has completed.** The only exception is T001/T002 (Phase 0 hardening), which are independent of 012 activation, still wait for freeze, and MUST NOT wait for SG1 (FR-160).
