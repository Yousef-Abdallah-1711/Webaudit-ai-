# Accessibility smoke report

## Status: initial structure only

The public page exposes semantic headings, landmarks/sections, links, buttons, a tab group, an FAQ with expanded/collapsed state, a table, textareas, and radio buttons in the inspected accessibility tree. This is not a complete accessibility audit.

Future checks: heading hierarchy, Arabic RTL/screen-reader order, named icon controls, keyboard operation of tabs/menu/accordion, visible focus, contrast for muted text and lime accents, form labels/errors, reduced motion, and mobile zoom/reflow.
